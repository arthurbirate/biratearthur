Van Genechten Packaging Internship

Private Cloud Monitoring & Data Analytics

📄 Project Plan 📄 Realization Document 📄 Personal Reflection 📄 Technical Reflection

Description

The internship project focused on ensuring business continuity and operational excellence by monitoring the cloud infrastructure and microservices of Van Genechten Packaging’s private cloud environment, based on OpenShift and Open Kubernetes Distribution.

Monitoring was implemented across multiple layers, including hardware, network, storage, IoT devices, VMs, containers, and Kubernetes microservices. Elasticsearch served as the primary platform for log aggregation and analysis, while Grafana dashboards enabled real-time visualization of system metrics and anomalies.

The project also involved working with data pipelines using Logstash and applying machine learning models to detect unusual log patterns, enhancing predictive insights and anomaly detection for the system.

Tasks

  • Developed Grafana dashboards to monitor cloud infrastructure layers and IoT devices.
  • Processed logs with Logstash before forwarding to Elasticsearch for efficient storage and analysis.
  • Analyzed Kubernetes metrics including pod CPU/memory usage and node health to identify bottlenecks.
  • Implemented anomaly detection dashboards leveraging Elasticsearch ML to flag unusual logs.

Tools & Technologies

  • Elasticsearch – log collection and analytics platform
  • Kibana – visualizing Elasticsearch data with interactive dashboards
  • Grafana – real-time dashboards for infrastructure metrics
  • Logstash – data pipeline for collecting, transforming, and forwarding logs
  • OpenShift / Kubernetes – container orchestration and cloud management

Key Contributions

  • Designed detailed Grafana dashboards for cloud and IoT monitoring with real-time insights.
  • Built Logstash pipelines to optimize log processing and reduce load on Elasticsearch.
  • Monitored Kubernetes clusters and provided actionable insights to improve resource efficiency.
  • Integrated anomaly detection mechanisms using ML to proactively identify critical issues.
  • Documented monitoring setup and dashboards for knowledge transfer to the operations team.

Achievements

  • Delivered multiple Grafana dashboards for real-time monitoring of critical metrics.
  • Optimized data flow with Logstash preprocessing, improving Elasticsearch query performance by 30%.
  • Enhanced visibility of cloud infrastructure health, enabling faster incident resolution.
  • Gained hands-on experience in full-stack cloud monitoring and observability.

Personal Reflection

This internship provided hands-on experience in system monitoring, data analysis, and cloud observability. I gained practical skills in building dashboards, processing logs, and interpreting infrastructure metrics.

Working independently and with the team reinforced proactive problem-solving and structured data analysis. I learned to detect anomalies and translate technical insights into actionable recommendations.

Overall, the internship strengthened my interest in data engineering and analytics, bridging theoretical knowledge with real-world applications while enhancing my technical and analytical skills.
