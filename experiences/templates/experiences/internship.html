Van Genechten Packaging Internship

Private Cloud Monitoring & Data Analytics

📄 Project Plan 📄 Realization Document 📄 Personal Reflection 📄 Technical Reflection

Description

The internship project focused on ensuring business continuity through the monitoring of cloud infrastructure and microservices within a private cloud environment based on OpenShift / Open Kubernetes Distribution. The project involved setting up continuous monitoring across various layers of the cloud architecture, including hardware, network, storage, IoT, hypervisors (VMs), containers, and applications. Elasticsearch was used for data collection and reporting, with Grafana utilized for creating interactive dashboards. In addition, IoT and application data monitoring were implemented to uncover valuable insights and trends. Machine learning techniques were employed to detect anomalies in logs, improving the identification of potential issues within the infrastructure. The project also included working with data pipelines using Logstash, gaining practical experience in data analytics. Skills were developed in data visualization, dashboard design, and the use of machine learning for log anomaly detection.

Tasks

  • Created dashboards in Grafana to monitor different parts of the cloud and IoT system.
  • Used Logstash to process and send logs to Elasticsearch.
  • Analyzed data from Kubernetes to check pod performance (CPU - memory).
  • Set up a dashboard for detecting unusual log patterns (anomaly detection).

Tools & Technologies

  • Elasticsearch
  • Kibana
  • Grafana
  • Logstash

Key Contributions

  • Designed and implemented dashboards in Grafana for monitoring cloud infrastructure and IoT metrics.
  • Used Logstash to parse and forward logs into Elasticsearch for visualization.
  • Monitored Kubernetes environments including pod CPU - memory usage and node-level metrics.
  • Created dashboards to track Red Hat license consumption and subscription status.
  • Set up anomaly detection for logs using machine learning features in Elasticsearch.

Achievements

  • Created multiple Grafana dashboards to monitor system metrics and performance.
  • Enhanced dashboard loading efficiency by configuring Logstash pipelines to preprocess and filter data, reducing the load on Elasticsearch and accelerating query response times.
