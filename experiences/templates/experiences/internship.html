Description

The internship focused on ensuring business continuity by monitoring cloud infrastructure and microservices within Van Genechten Packaging’s private cloud environment, based on OpenShift / Open Kubernetes Distribution.

Monitoring was set up across hardware, network, storage, IoT devices, virtual machines, containerized applications, and Kubernetes microservices. Elasticsearch handled log aggregation and analysis, while Grafana dashboards provided real-time visualization of metrics and anomalies.

Data pipelines were implemented using Logstash to preprocess, transform, and forward logs. Machine learning techniques were applied for anomaly detection, allowing predictive insights and proactive identification of potential issues.

Tasks

  • Developed and configured Grafana dashboards to monitor VMs, containers, and IoT devices.
  • Processed, filtered, and enriched logs with Logstash before sending to Elasticsearch.
  • Analyzed Kubernetes metrics including pod CPU/memory usage, node health, and container performance.
  • Implemented anomaly detection dashboards leveraging Elasticsearch ML to flag unusual log patterns.

Tools & Technologies

  • Elasticsearch – log collection and search analytics platform
  • Kibana – visualizing Elasticsearch data and creating interactive dashboards
  • Grafana – real-time dashboards for infrastructure metrics
  • Logstash – data pipeline tool for collecting, transforming, and forwarding logs
  • OpenShift / Kubernetes – container orchestration and cloud management

Key Contributions

  • Designed and implemented detailed Grafana dashboards for cloud and IoT monitoring, enabling stakeholders to track infrastructure health in real-time.
  • Developed Logstash pipelines for log processing, which reduced the load on Elasticsearch and accelerated query performance.
  • Monitored Kubernetes clusters, analyzed node and pod metrics, and provided actionable recommendations to improve resource efficiency.
  • Integrated anomaly detection mechanisms using machine learning to proactively identify critical issues before they impacted production systems.
  • Documented monitoring setup and dashboards to facilitate knowledge transfer to the operations team.

Achievements

  • Successfully delivered multiple Grafana dashboards covering all critical cloud and IoT metrics for real-time monitoring.
  • Optimized data flow through Logstash preprocessing, reducing Elasticsearch query times by more than 30%.
  • Enhanced visibility of cloud infrastructure health, contributing to faster incident detection and resolution.
  • Gained practical expertise in full-stack cloud monitoring and observability within a private enterprise environment.

Personal Reflection

This internship provided a hands-on introduction to system monitoring, data analysis, and cloud observability. I gained practical experience in building dashboards, processing logs, and interpreting infrastructure metrics using Grafana, Kibana, Elasticsearch, and Logstash.

Working independently and collaborating with the team taught me the importance of proactive problem-solving and structured data analysis. I learned to identify key performance indicators, detect anomalies, and translate technical insights into actionable recommendations.

Overall, this internship reinforced my interest in pursuing a career in data engineering and analytics. It allowed me to bridge theoretical knowledge with practical applications, develop analytical thinking, and strengthen my technical skillset for future professional challenges.
