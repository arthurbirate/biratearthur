Van Genechten Packaging Internship

Private Cloud Monitoring & Data Analytics

Project Plan Realization Document Personal Reflection Technical Reflection

Description

The internship focused on ensuring business continuity by monitoring cloud infrastructure and microservices within Van Genechten Packaging’s private cloud environment, based on OpenShift / Open Kubernetes Distribution.

Monitoring was set up across hardware, network, storage, IoT devices, virtual machines, containerized applications, and Kubernetes microservices. Elasticsearch handled log aggregation and analysis, while Grafana dashboards provided real-time visualization of metrics and anomalies.

Data pipelines were implemented using Logstash to preprocess, transform, and forward logs. Machine learning techniques were applied for anomaly detection, allowing predictive insights and proactive identification of potential issues.

Tasks

  • Developed and configured Grafana dashboards to monitor VMs, containers, and IoT devices.
  • Processed, filtered, and enriched logs with Logstash before sending to Elasticsearch.
  • Analyzed Kubernetes metrics including pod CPU/memory usage, node health, and container performance.
  • Implemented anomaly detection dashboards leveraging Elasticsearch ML to flag unusual log patterns.

Tools & Technologies

  • Elasticsearch – log collection and search analytics platform
  • Kibana – visualizing Elasticsearch data and creating interactive dashboards
  • Grafana – real-time dashboards for infrastructure metrics
  • Logstash – data pipeline tool for collecting, transforming, and forwarding logs
  • OpenShift / Kubernetes – container orchestration and cloud management

Key Contributions

  • Designed Grafana dashboards for cloud and IoT monitoring with real-time insights.
  • Developed Logstash pipelines to optimize log processing and reduce Elasticsearch load.
  • Monitored Kubernetes clusters and provided actionable insights to improve efficiency.
  • Integrated anomaly detection mechanisms using machine learning to identify critical issues.
  • Documented monitoring setup and dashboards for knowledge transfer to the operations team.

Achievements

  • Delivered multiple Grafana dashboards covering critical cloud and IoT metrics.
  • Optimized data flow through Logstash, improving Elasticsearch query performance by 30%.
  • Enhanced infrastructure visibility, enabling faster incident detection and resolution.
  • Gained hands-on experience in full-stack cloud monitoring and observability.

Personal Reflection

This internship provided hands-on experience in system monitoring, data analysis, and cloud observability. I learned to build dashboards, process logs, and interpret infrastructure metrics using Grafana, Kibana, Elasticsearch, and Logstash.

Working both independently and collaboratively reinforced proactive problem-solving, structured data analysis, and the ability to translate technical insights into actionable recommendations.

Overall, this experience strengthened my interest in pursuing a career in data engineering and analytics, bridging theoretical knowledge with practical applications while enhancing my technical and analytical skills.
