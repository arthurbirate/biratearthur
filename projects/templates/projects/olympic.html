Objective

The goal of this project was to design an intuitive and interactive Qlik Sense dashboard that allows users to explore Olympic Games data from 1980 to 2022. The dashboard focused on deeper insights beyond medal counts, including:

  • Trends in medal distribution by country and sport.
  • Gender performance – comparing male and female athlete participation and success.
  • Sport-specific breakdowns with drill-through capabilities.
  • Athlete achievements with individual profiles and medal history.
  • Age and gender dynamics across different events.

Designed as a self-service BI tool for sports fans, journalists, and Olympic committees, it provided both high-level KPIs and detailed drilldowns.

Dataset

The dashboard used publicly available Olympic Games data from 1980–2022, covering athletes, medals, countries, sports, and events. Key preprocessing tasks were handled in Qlik’s load editor:

  • Standardized inconsistent country codes (e.g., USSR → Russia).
  • Cleaned duplicate or incomplete athlete records.
  • Reshaped medal data for time-series analysis.
  • Created a star-schema-like model for efficient drill-down performance.

These steps ensured the dashboard could handle large historical datasets while remaining responsive for interactive use.

Results

The final dashboard delivered a multi-sheet Qlik Sense application combining medal tracking, gender analysis, sport-specific insights, and athlete-level details:

  • Dynamic Medal Tracking: Filtering by year, country, gender, or sport.
  • Gender Performance: Showed the steady rise of female participation and medal wins since the 1980s.
  • Sport-Specific Trends: Identified shifts in dominance across athletics, swimming, and gymnastics.
  • Athlete Achievements: Profiles displaying medal totals and histories of legendary Olympians.
  • Age Dynamics: Patterns showing younger athletes excel in gymnastics/sprints, older athletes in endurance sports.

Key Learnings

  • Mastered Qlik load scripting for cleaning, reshaping, and modeling Olympic data.
  • Applied set analysis for advanced filtering and dynamic measures (e.g., medals by gender).
  • Optimized dashboard performance by improving joins and pre-aggregating metrics.
  • Learned to design effective multi-sheet dashboards with summary KPIs and detailed drilldowns.
  • Developed storytelling skills for both casual users and analysts.
  • Built domain expertise in Olympic data – evolving country codes, gender participation, and event growth.
