Objective: The goal of this project was to design an intuitive and interactive Qlik Sense dashboard that allows users to explore Olympic Games data from 1980 to 2022. The dashboard focused not just on medal counts, but also on deeper insights such as:

  • Trends in medal distribution by country and sport.
  • Gender performance – comparing male and female athlete participation and success.
  • Sport-specific breakdowns with drill-through capabilities.
  • Athlete achievements with individual profiles and medal history.
  • Age and gender dynamics across different events.

It was designed as a self-service BI tool for sports fans, journalists, and Olympic committees, providing both high-level KPIs and detailed drilldowns.

Dataset: The dashboard used publicly available Olympic Games data from 1980–2022, covering athletes, medals, countries, sports, and events. Key preprocessing tasks were handled in Qlik’s load editor:

  • Standardized inconsistent country codes (e.g., USSR → Russia).
  • Cleaned duplicate or incomplete athlete records.
  • Reshaped medal data for time-series analysis.
  • Created a star-schema-like model for efficient drill-down performance.

This ensured the dashboard could handle large historical datasets while remaining responsive for interactive use.

Results: The final dashboard delivered a multi-sheet Qlik Sense application that combined medal tracking, gender analysis, sport-specific insights, and athlete-level details.

  • Dynamic Medal Tracking: Users could filter by year, country, gender, or sport. Example: USA’s dominance in Summer Games, Norway’s strength in Winter skiing.
  • Gender Performance: Showed the steady rise of female participation and medal wins since the 1980s.
  • Sport-Specific Trends: Identified shifts in dominance across disciplines like athletics, swimming, and gymnastics.
  • Athlete Achievements: Profiles displayed medal totals and participation histories of legendary Olympians.
  • Age Dynamics: Revealed patterns where younger athletes dominated sprint/gymnastics, while older athletes excelled in endurance or skill-based events.
Key Learnings:
  • Mastered Qlik load scripting for cleaning, reshaping, and modeling Olympic data.
  • Applied set analysis for advanced filtering and dynamic measures (e.g., medals by gender).
  • Improved dashboard performance by optimizing joins and pre-aggregating metrics.
  • Learned how to design effective multi-sheet dashboards with both summary KPIs and detailed drilldowns.
  • Gained skills in visual storytelling – balancing simplicity for casual users with depth for analysts.
  • Built domain knowledge in Olympic data challenges: evolving country codes, gender participation changes, and growth in events.

Technologies Used

  • Qlik Sense
  • Qlik Load Script
  • Data Modeling
  • Set Analysis
  • Data Visualization
