Objective

The goal of this project was to design an interactive Qlik Sense dashboard that explores Olympic Games data from 1980 to 2022. The dashboard highlights insights such as:

  • Trends in medal distribution by country and sport
  • Gender performance — male vs female athlete participation and success
  • Sport-specific breakdowns with drill-through capabilities
  • Athlete achievements with individual profiles and medal history
  • Age and gender dynamics across different events

Designed as a self-service BI tool for sports fans, journalists, and Olympic committees, it provided both high-level KPIs and detailed drilldowns.

Dataset

The dashboard used Olympic Games data from 1980–2022, covering athletes, medals, countries, sports, and events. Preprocessing was handled in Qlik’s load editor:

  • Standardized inconsistent country codes (e.g., USSR → Russia)
  • Cleaned duplicate or incomplete athlete records
  • Reshaped medal data for time-series analysis
  • Created a star-schema-like model for efficient drill-down performance

These steps ensured the dashboard could handle large datasets while staying responsive.

Results

The final Qlik Sense application combined medal tracking, gender analysis, sport-specific insights, and athlete-level details:

  • Dynamic medal tracking with filters for year, country, gender, and sport
  • Gender analysis showing the steady rise of female participation since the 1980s
  • Sport-specific trends highlighting shifts in dominance across athletics, swimming, and gymnastics
  • Athlete profiles displaying medal totals and career histories
  • Age patterns showing younger athletes excel in gymnastics, older athletes in endurance sports

Key Learnings

  • Mastered Qlik load scripting for cleaning, reshaping, and modeling data
  • Applied set analysis for advanced filtering and dynamic measures
  • Optimized dashboard performance with efficient joins and pre-aggregation
  • Designed multi-sheet dashboards with summary KPIs and drilldowns
  • Improved storytelling for casual users and analysts alike
  • Developed domain expertise in Olympic data trends and participation

Technologies Used

  • Qlik Sense
  • Qlik Load Script
  • Data Modeling
  • Set Analysis
  • Data Visualization
