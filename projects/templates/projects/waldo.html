Object Detection with YOLOv5 & YOLOv8: Where’s Waldo? (Artificial Intelligence Project)

Objective: The main goal of this project was to solve the famous puzzle of finding “Waldo” in large and crowded images. Waldo is usually very small and hidden among hundreds of other distracting characters and objects. To make this task possible, I designed a computer vision system using state-of-the-art object detection models. The final solution was able to accurately and quickly find Waldo in images that were very challenging for humans.

Dataset: I collected more than 200 high-resolution images from Where’s Waldo books and online sources. Each image had Waldo hidden in a different position. To train the model, I manually annotated each image using Roboflow, drawing bounding boxes around Waldo. The dataset was divided into training, validation, and testing sets. To make the model more robust, I used data augmentation techniques such as flipping images, adding blur, and changing brightness. This helped the model learn to detect Waldo even in difficult conditions like poor lighting or different rotations.

Model Training: I experimented with two popular deep learning object detection models: YOLOv5 and YOLOv8. - Both models were trained separately so I could compare their accuracy and speed. - I used transfer learning by starting with pretrained weights, which allowed the models to learn faster and more effectively. - I adjusted hyperparameters such as image size, batch size, learning rate, and confidence thresholds to improve performance. - During training, I evaluated the models continuously to make sure they were not overfitting.

Challenge of Small Object Detection: Waldo is usually very small compared to the entire page, sometimes less than 1% of the total image. Standard object detection models often fail in this case. To solve this, I integrated SAHI (Slicing Aided Hyper Inference). SAHI divides each large image into smaller overlapping tiles. Each tile is processed separately, and then all results are combined to get the final detection. This method made a huge difference: it increased recall (finding Waldo when he was present) and improved precision (avoiding false detections of other characters).

Results: - The YOLOv8 + SAHI combination achieved the best accuracy (highest mean Average Precision). - It was much better than YOLOv5, especially in crowded and complex scenes. - Despite using slicing, the inference speed remained very efficient. This means the system can be used both in batch mode (processing many images) and near real-time scenarios.

Key Learnings: From this project, I learned several important lessons: - Why slicing is necessary when detecting very small objects in large images. - How to apply and fine-tune modern object detection models like YOLOv5 and YOLOv8. - How to use Roboflow for dataset annotation and augmentation effectively. - How to evaluate, compare, and optimize deep learning models for real-world tasks. - How to balance model accuracy and speed for practical applications.
