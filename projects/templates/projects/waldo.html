Object Detection with YOLOv5 & YOLOv8: Where’s Waldo? (Artificial Intelligence Project)

Objective: The main goal of this project was to solve the famous puzzle of finding “Waldo” in large and crowded images. Waldo is usually very small and hidden among hundreds of other distracting characters and objects. To make this task possible, I designed a computer vision system using state-of-the-art object detection models. The final solution was able to accurately and quickly find Waldo in images that were very challenging for humans.

Dataset: I collected more than 200 high-resolution images from Where’s Waldo books and online sources. Each image had Waldo hidden in a different position. To train the model, I manually annotated each image using Roboflow, drawing bounding boxes around Waldo. The dataset was divided into training, validation, and testing sets. To make the model more robust, I used data augmentation techniques such as flipping images, adding blur, and changing brightness.

Model Training: I experimented with two popular deep learning object detection models: YOLOv5 and YOLOv8. - Both models were trained separately so I could compare their accuracy and speed. - I used transfer learning by starting with pretrained weights. - I adjusted hyperparameters such as image size, batch size, learning rate, and confidence thresholds. - During training, I continuously evaluated the models to avoid overfitting.

Challenge of Small Object Detection: Waldo is usually very small compared to the entire page, sometimes less than 1% of the total image. Standard object detection models often fail in this case. To solve this, I integrated SAHI (Slicing Aided Hyper Inference). SAHI divides each large image into smaller overlapping tiles. Each tile is processed separately, and then all results are combined. This greatly improved recall (finding Waldo when present) and precision (avoiding false detections).

Results: - The YOLOv8 + SAHI combination achieved the best accuracy (highest mAP). - It outperformed YOLOv5, especially in crowded and complex scenes. - Despite slicing, inference speed remained efficient — suitable for both batch and near real-time use.

Key Learnings:
  • Why slicing is necessary when detecting very small objects in large images.
  • How to apply and fine-tune modern object detection models like YOLOv5 and YOLOv8.
  • How to use Roboflow for dataset annotation and augmentation effectively.
  • How to evaluate, compare, and optimize deep learning models for real-world tasks.
  • How to balance model accuracy and speed for practical applications.
