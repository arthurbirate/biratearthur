Object Detection with YOLOv5 & YOLOv8: Where’s Waldo? (Artificial Intelligence Project)

Objective: The goal of this project was to solve the famous puzzle of finding “Waldo” in large and crowded images. Waldo is usually very small and hidden among hundreds of distracting characters. Using state-of-the-art object detection models, I developed a computer vision system capable of accurately locating Waldo in challenging images.

Dataset: I collected 200+ high-resolution images from Where’s Waldo books and online sources. Each image was manually annotated using Roboflow, drawing bounding boxes around Waldo. The dataset was divided into training, validation, and testing sets, with data augmentation (flipping, blurring, brightness changes) applied to increase robustness.

Model Training: I trained two models, YOLOv5 and YOLOv8, separately to compare accuracy and inference speed. - Used transfer learning from pretrained weights. - Tuned hyperparameters (image size, batch size, learning rate). - Regular evaluation during training helped prevent overfitting. This experimentation allowed me to balance model precision and performance.

Challenge of Small Object Detection: Waldo often occupied less than 1% of an image, making him difficult for standard object detectors. To address this, I used SAHI (Slicing Aided Hyper Inference), which slices large images into smaller overlapping tiles. Processing each tile separately improved both recall (finding Waldo) and precision (avoiding false positives).

Results: The YOLOv8 + SAHI combination achieved the highest accuracy (mAP) and significantly outperformed YOLOv5 in complex scenes. Even with slicing, inference remained fast enough for near real-time detection.

Key Learnings:
  • Why slicing is essential for detecting small objects in large images.
  • How to fine-tune and evaluate deep learning models like YOLOv5 and YOLOv8.
  • Effective dataset annotation and augmentation with Roboflow.
  • Balancing speed and accuracy for real-world applications.
  • Applying object detection to fun but challenging tasks like “Where’s Waldo?”.
